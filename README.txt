Задачи "Робот на клетчатом поле" (HorizonSideRobots)

  task01..15.jl     самодостаточные решения задач: главная функция сверху, ниже - только
                    используемые ею вспомогательные функции (контракт ДАНО/РЕЗУЛЬТАТ,
                    утверждения #УТВ, инварианты - оформление по лекциям 2 и 3);
                    при include сами запускаются на поле из fields/
                    (кроме запуска из demo.jl / test_all.jl)
  fields/           поля-примеры для каждой задачи (taskNN.sit)

Проверка на примерах (запускать из этой папки):
  julia demo.jl               все задачи: поле до/после в виде текста + OK/ОШИБКА
  julia demo.jl 5 11          только задачи 5 и 11
  julia demo.jl 6 anim        задача 6 с анимацией в окне (нужен пакет GLMakie)
  julia demo.jl all anim      все задачи с анимацией, Enter - следующая

Обозначения в текстовой картинке:
  @ робот, (@) робот на маркере, * маркер, # недоступная клетка
  (внутри прямоугольной перегородки), | и --- стены

Остальное:
  julia test_all.jl [N]       случайные тесты, N полей на задачу (по умолчанию 300)
  julia make_fields.jl        пересоздать поля-примеры в fields/
  testlib.jl                  построение полей и проверка результатов (для demo и тестов)

Свой пример: create_sit(8, 10; newfile = "my.sit") - нарисовать поле мышью,
затем r = Robot("my.sit", animate = true); include("task06.jl"); task6!(r)
